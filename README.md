# FACEIT Server Ping & Route Inspector

Расширение для Google Chrome для определения пинга и маршрута сервера FACEIT перед подключением к матчу.

## Установка

1. Откройте `chrome://extensions/` в Google Chrome.
2. Включите **Режим разработчика** в правом верхнем углу.
3. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.
4. Для включения точного локального замера запустите файл `native_host/install_host.bat` (один клик).
